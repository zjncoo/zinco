Tessere Fedeltà Personalizzate

Come funziona:
  • Carica il PDF template della tessera.
  • Carica il file CSV con le colonne Nome e Cognome.
  • Clicca su "Genera tessere PDF in ZIP" per scaricare tutte le tessere in un unico file ZIP.
  • Ogni tessera sarà un PDF singolo personalizzato con Nome e Cognome.
